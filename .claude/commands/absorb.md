Do not simply comply. Make the correction unnecessary in future.

Decide which of these is the right home for it, and say why:

- **A test** — if it is a property that must always hold. Preferred; a test catches the
  problem rather than reminding you about it.
- **A hook** — if it must be prevented rather than detected, or if detection is too late.
- **A type** — if the compiler can make the mistake unrepresentable. Best of all when available.
- **`CLAUDE.md`** — only if none of the above can express it. This is the weakest option,
  because it relies on being read and remembered.
